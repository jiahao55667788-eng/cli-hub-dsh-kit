  1. 装包管理器：pip install cli-anything-hub（本机已装在隔离 venv，`cli-hub` 已在 PATH）
  2. 找工具：cli-hub search video / cli-hub can "edit a video"
  3. 装上即用：cli-hub install kdenlive → cli-anything-kdenlive --help
